# Azure Administration Labs

**Praktiske prosjekter innen Microsoft Azure, skyadministrasjon, sikkerhet og IT-drift.**

## Om porteføljen

Dette repositoryet dokumenterer mine praktiske Azure-prosjekter og min kompetanseutvikling innen skyadministrasjon og IT-infrastruktur.

Jeg har bachelorgrad i dataingeniørfag fra Høgskulen på Vestlandet (HVL), har bestått Microsoft Azure Fundamentals (AZ-900) og arbeider videre mot Azure Administrator (AZ-104).

Målet er å bygge og dokumentere praktisk erfaring med å konfigurere, administrere, sikre og overvåke skyressurser. På lengre sikt ønsker jeg å utvikle kompetansen videre innen Cloud Engineering og DevOps.

## Prosjekter

| Prosjekt | Innhold | Status |
|---|---|---|
| [01 – Azure Storage](01-azure-storage/README.md) | Blob Storage, Azure RBAC, nettverkssikkerhet, Azure Monitor og kostnadskontroll | Gjennomført |

Nye prosjekter legges til fortløpende etter hvert som de blir gjennomført.

## Teknologier og kompetanseområder

- Microsoft Azure og Azure Portal
- Azure Storage og Blob Storage
- Microsoft Entra ID og Azure RBAC
- Nettverkssikkerhet og tilgangskontroll
- Azure Monitor, Metrics og Alerts
- Azure Cost Management

## Dokumentasjon

Hvert prosjekt har sin egen mappe med prosjektmål, teknisk gjennomføring, sikkerhetstiltak, praktiske tester, skjermbilder og læringsutbytte. Dokumentasjonen er skrevet på norsk; Azure-tjenestenavn og filnavn beholdes på engelsk.

## Videre utvikling

Planlagte kompetanseområder inkluderer virtuelle maskiner, virtuelle nettverk, identitetsstyring, backup og automatisering. Senere kan porteføljen utvides med Azure CLI, PowerShell, Bicep, Terraform og CI/CD.

> **Merk:** Prosjektene er lærings- og laboratorieøvelser, ikke produksjonsløsninger. Fremtidige prosjekter blir ikke oppført som gjennomført før de er testet og dokumentert.
